
Designed and deployed a cutting-edge recruitment system powered by modular, privacy-first AI. The system integrates multiple agents to streamline processes like job description summarization, resume parsing, candidate matching, and interview scheduling. Highlights:

Leveraged Ollama LLM models and semantic embeddings for precise candidate-job matching.

Enabled data handling using SQLite for secure and efficient storage.

Delivered automation in candidate shortlisting with personalized interview invitations.

Enhanced scalability with a multi-agent framework built for privacy and innovation.
